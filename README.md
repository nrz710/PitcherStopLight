# Team logos

Drop your club's logo here, named by the team abbreviation Baseball Savant uses
(`MIL.png`, `CHC.svg`, `NYY.webp`, …). Supported: `.png`, `.svg`, `.webp`, `.jpg`.

The dashboard detects the pitcher's most recent team from the Savant file and
shows `assets/logos/<TEAM>.<ext>` at 25% opacity behind his name.

Team logos are trademarks of MLB and its clubs. Only commit logo files you have
the rights to use, and think twice before committing them to a public repository.
